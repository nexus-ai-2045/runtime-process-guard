# 全プロセス表

## 対象機能

観測できた全件の表示、検索、負荷列の並べ替え。

## ユーザーが開く場所

メニューバーの「全体 …件」（観測前は「監視 更新中」）から「全件を表で表示」を選ぶ。「プロセス観測・全件保護」ウィンドウの「全プロセス」タブを使う。

## 実機での操作

1. メニューの項目を選ぶ前後で画面を読み取る。選択後にウィンドウが開き、行が表示されることを確認する。
2. 表で確認した名前の一部を「プロセスを検索」に入力し、行数が減り、表示された行に検索語が一致することを確認する。検索を消し、全件に戻ることを確認する。
3. 「今すぐ更新」で2回目の観測を行い、更新終了後に異なる測定値があることを確認する。`CPU %`の列見出しをクリックし、表示された数値が単調に並ぶことを確かめる。再クリック後に順序が反転することも確認する。クリックのたびに画面を読み直す。

## 注意点

初回観測や一部の行の負荷は未測定になる。測定値が比較できない場合は負荷順を未確認とする。合成データのプロセス番号順検査は実機の負荷順の証拠に含めない。
